YOLO Object Detection

About the Project

This project uses YOLO and OpenCV to detect objects in real time through a camera.

Files

- "yolo.ipynb": Jupyter Notebook containing the project code.

Technologies

- Python
- YOLOv8
- OpenCV
- Ultralytics

Features

- Real-time object detection.
- Detecting selected object classes.
- Displaying the number of detected objects.
- Using a camera for live detection.

Goal

To explore Computer Vision and real-time object detection using YOLO.

Status

Educational Project
